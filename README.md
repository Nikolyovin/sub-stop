# 🛑 Стоп-Подписка (Sub-Stop)

**Трекер подписок и регулярных платежей для Android.**

Приложение помогает контролировать расходы, не забывать о скрытых списаниях и триальных периодах, а также видеть полную картину своих финансовых обязательств в одном месте.

## ✨ Основные возможности

- 📊 **Дашборд расходов** — мгновенный подсчет трат в месяц и в год.
- 📅 **Календарь списаний** — наглядный график всех платежей (доступно в Premium).
- 🔔 **Умные уведомления** — напоминания за день до списания с учетом триалов.
- 🌍 **Мультивалютность** — поддержка RUB, USD, EUR с автоматической конвертацией по курсу ЦБ РФ.
- 🔒 **Безопасность** — вход в приложение по биометрии (отпечаток пальца / Face ID).
- 📈 **Статистика** — круговая диаграмма трат по категориям с возможностью экспорта.
- 🌗 **Темы** — адаптивная светлая и темная темы.
- 🎨 **Умное распознавание брендов** — автоподстановка иконок и цветов для популярных сервисов (Яндекс, Сбер, Netflix и др.).

## 🛠 Технологический стек

- **Фреймворк:** React Native (Expo SDK 58) + TypeScript
- **Стейт-менеджмент:** Zustand (с persist в AsyncStorage)
- **Анимации и жесты:** React Native Reanimated, Gesture Handler
- **Монетизация:** Yandex Mobile Ads (Баннеры + Interstitial)
- **Работа с датами:** date-fns
- **Бэкенд (Premium):** Кастомный API на Node.js (хостинг Amvera) + Робокасса

## 🚀 Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npx expo start
```
